WEB-TOYBOX · WIDGET 01

ใส่เกมยิงยานอวกาศ
ลงเว็บไหนก็ได้ ด้วยโค้ดบรรทัดเดียว

destroyer เปลี่ยนหน้าเว็บของคุณให้เป็นด่านเกม ผู้เล่นขับยานพิกเซลยิงหัวข้อ ปุ่ม และรูปให้แตกกระจาย ทั้งหมดเป็นแค่ภาพ กดออกเมื่อไรหน้าเว็บก็กลับมาเหมือนเดิมทุกอย่าง

เริ่มติดตั้ง ดาวน์โหลด destroyer.js
  • 1บรรทัดในการติดตั้ง
  • ~20 kBไฟล์เดียวจบ (gzip)
  • 0ไลบรารีที่ต้องลงเพิ่ม

ทำไมใส่แล้วไม่ต้องกังวล

ออกแบบมาให้วางลงเว็บที่ใช้งานจริงได้โดยไม่กระทบของเดิม

ไม่พังของจริง

สิ่งที่ถูกยิงแค่ถูกซ่อนด้วย visibility: hidden ไม่ได้ถูกลบ เลย์เอาต์ไม่ขยับ และคืนค่าเดิมทุกอย่างเมื่อออกจากเกม

ไม่ชนกับ CSS เดิม

ปุ่ม เมนู และหน้าจอเกมอยู่ใน Shadow DOM ของตัวเอง สไตล์ของเว็บคุณจึงไม่ตีกัน

ไฟล์เดียวจบ

ไม่ต้องลง framework ไม่ต้องตั้งค่า build แค่มีไฟล์ .js หนึ่งไฟล์บนเว็บของคุณ

เล่นบนมือถือได้

ลากนิ้วเพื่อบังคับยาน รองรับจอที่มีรอยบากและขอบโค้ง

ติดตั้งใน 4 ขั้นตอน

ใช้ได้กับเว็บทุกแบบที่ใส่แท็ก <script> ได้

  1. ดาวน์โหลดไฟล์

    กดปุ่ม ดาวน์โหลด หรือ build เองจาก repo แล้วจะได้ไฟล์ dist/destroyer.js 

    npm install
npm run build

  2. อัปโหลดขึ้นเว็บ

    วางไฟล์ไว้ที่เดียวกับหน้าเว็บ หรือที่ไหนก็ได้ที่เปิดผ่าน URL ได้ เช่น /js/destroyer.js

  3. วางแท็ก script

    ใส่บรรทัดนี้ไว้ก่อนปิด </body> ปรับ path ให้ตรงกับที่อัปโหลด

    <script src="/js/destroyer.js" defer></script>

  4. เปิดหน้าเว็บ

    ปุ่ม 💥 DESTROY จะโผล่ที่มุมขวาล่าง กดแล้วเริ่มเล่นได้ทันที

ตั้งค่า

ใส่ data-attribute ไว้บนแท็ก <script> ไม่ใส่ก็ใช้ค่าเริ่มต้น

attribute ค่าเริ่มต้น ใช้ทำอะไร
data-position bottom-right มุมของปุ่ม: bottom-right, bottom-left, top-right, top-left (ถ้าใส่ค่าอื่นจะใช้ bottom-right แทน)
data-scope body CSS selector จำกัดพื้นที่ที่ทำลายได้ เช่น main หรือ #content
data-wd-ignore — ใส่ที่ element ใดก็ได้ในหน้า (ไม่ใช่ที่ script) เพื่อกันไม่ให้ส่วนนั้นถูกทำลาย

สร้างโค้ดของคุณ

วิธีเล่น

กดปุ่ม 💥 DESTROY แล้วเลือกเวลา 2, 5 หรือ 10 นาที ทำลายให้ได้ 100% ก่อนหมดเวลา ยิ่งเหลือเวลามาก ยิ่งได้โบนัส (50 คะแนนต่อวินาที)

  • เมาส์ / นิ้ว

    ขยับเพื่อบังคับยาน ยานจะลอยตามไปอย่างนุ่มนวล

  • ยิงอัตโนมัติ

    เมื่อมีเป้าในวงจุดรอบยาน ยานจะหันหัวไปหาเป้าแล้วยิงเอง

  • 1 / 2 / 3

    ใช้ไอเทมในช่องนั้น บนมือถือแตะที่ช่องไอเทมด้านล่างจอ

  • ขอบจอ

    พายานไปใกล้ขอบบนหรือล่างเพื่อเลื่อนหน้า ยิ่งใกล้ขอบยิ่งเร็ว

  • Esc

    ออกจากเกม หน้าเว็บจะกลับมาเหมือนเดิมทันที

ไอเทม

ของที่แตกอาจทิ้งกล่องไอเทมไว้ (ยิ่งใหญ่ยิ่งมีโอกาส) บินไปเก็บได้สูงสุด 3 ชิ้น กล่องจะหายไปใน 14 วินาที และกะพริบก่อนหาย

ระเบิด ทำลายหนักทุกอย่างในรัศมีรอบตัวยาน พร้อมคลื่นกระแทก
ยิงรัว ยิงเร็วขึ้น 3 เท่า นาน 8 วินาที
เลเซอร์ ลำแสงกากบาทแนวนอนและแนวตั้งผ่านตัวยาน ทะลุทุกอย่างที่ขวาง
แม่เหล็ก ดูดกล่องไอเทมใกล้ ๆ เข้าหายาน นาน 8 วินาที

คะแนน

  • ยิงโดน +1 ทำลายได้ HP สูงสุด × 10
  • ทำลายต่อเนื่องภายใน 1.4 วินาทีจะนับเป็นคอมโบ ทุก 3 คอมโบตัวคูณคะแนนเพิ่มขึ้น 1 สูงสุด x5
  • สถิติสูงสุดเก็บแยกตามเวลาที่เลือก ในเบราว์เซอร์ของคุณเอง

กล่องใหญ่อย่างการ์ดหรือแถบเมนูจะยิงไม่เข้า จนกว่าทุกอย่างข้างในจะแตกหมด ลองเก็บตัวหนังสือและปุ่มก่อน แล้วค่อยกะเทาะหน้าเว็บออกทีละชั้น ระเบิดกับเลเซอร์ทำลายจากข้างในออกมาได้ในคราวเดียว

คำถามที่พบบ่อย

ทำลายแล้วเว็บพังจริงไหม

ไม่พัง ทุกอย่างเป็นแค่ภาพบนหน้าจอของผู้เล่นคนนั้น ไม่มีการลบ element และไม่ได้แก้ไขอะไรบนเซิร์ฟเวอร์ กดออกแล้วหน้าเว็บกลับมาเหมือนเดิม

ทำให้เว็บช้าลงไหม

ไฟล์โหลดแบบ defer จึงไม่บล็อกการแสดงผล และไม่ทำงานอะไรเลยจนกว่าจะมีคนกดปุ่มเล่น

อยากกันบางส่วนไม่ให้โดนยิง

ใส่ data-wd-ignore ที่ element นั้น ทั้งตัวมันและทุกอย่างข้างในจะไม่ถูกนับเป็นเป้า หรือใช้ data-scope จำกัดพื้นที่ทั้งหมด

ใช้กับ WordPress, React หรือ Vue ได้ไหม

ได้ ขอแค่ใส่แท็ก <script> ลงในหน้าได้ ไม่ต้องพึ่งเฟรมเวิร์กใด

มีการโหลดอะไรจากภายนอกไหม

มีแค่ฟอนต์ Press Start 2P และ Kanit จาก Google Fonts ตอนเปิดเกม ถ้าโหลดไม่ได้จะใช้ฟอนต์ในเครื่องแทน
