ของเล่นเล็ก ๆ ที่ฝังลงเว็บไหนก็ได้ ด้วยแท็กเดียว

แต่ละวิดเจ็ตเป็นไฟล์ JavaScript ไฟล์เดียว ไม่ต้องลงอะไรเพิ่ม ไม่ชนกับหน้าตาเว็บเดิม และเอาออกได้ทุกเมื่อแค่ลบแท็กนั้นทิ้ง

ใช้ยังไง

ทุกวิดเจ็ตใช้แบบเดียวกัน วางแท็ก script บรรทัดเดียวไว้ก่อนปิด </body> 

<script src="https://minttnim19.github.io/web-toybox/v0.1.0/ชื่อวิดเจ็ต.js" defer></script>
  • ลิงก์ที่มีเลขเวอร์ชัน เช่น /v0.1.0/ ไม่เปลี่ยนแปลงตลอดไป เหมาะกับเว็บที่ใช้งานจริง ถ้าอยากได้ของใหม่ล่าสุดเสมอ ให้ตัดเลขเวอร์ชันออก
  • ตั้งค่าแต่ละวิดเจ็ตด้วย data-attribute บนแท็กเดียวกัน ดูได้ในคู่มือของวิดเจ็ตนั้น
  • อยากเก็บไฟล์ไว้บนเว็บตัวเอง ดาวน์โหลดได้จากหน้าคู่มือ หรือ build จาก repo ด้วย npm run build
